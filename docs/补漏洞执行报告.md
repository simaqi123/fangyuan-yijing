## 二、重要发现（修正上一轮审计）

DGX 上的**权威版代码（unified_brain_mcp.py 56KB）远新于本地副本（17KB）**。昨天 OpenClaw/另一会话已经在 DGX 上建好了「义理层雏形」，我的记忆日志没记到：

- **六十四卦语义骨架**：`gua64.py`（64 卦的卦辞/大象传/核心义/现代语义标签）+ `gua_assign.py`（把 16 万 chunks 全量归卦到 `kb_policy.db`）
- **`gua_search` 已接入 MCP**：给任意自然语言，返回最贴近的卦位 + 该卦下的文献，这就是「先定卦、再找材料」的义理入口
- 知识库保留策略 `kb_policy.py` v3、trigram 子串索引、自产记忆 `self_memory_search` 双路召回

**结论修正**：义理层不是"从零建"，而是"已有六十四卦骨架，需要深化"。后续规划据此调整。

- 上传：scp 两个文件 → md5 核对
- 重启：8787 用 `restart_api.py` 精确重启；OpenClaw 侧 `systemctl --user restart openclaw-gateway.service`

**一个教训**：OpenClaw 的 MCP 是 lazy spawn（按需启动），直接 kill 进程 supervisor 不会自动拉起，需重启 gateway 恢复。已记录到 restart 脚本注释。
