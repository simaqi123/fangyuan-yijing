## 一、这篇文章教会了什么

文章讲的是**邵雍先天六十四卦方圆图**，一句话点破核心：

> **圆图管时间，方图管空间。** 时空（时间+空间）组合起来才能用。

具体拆成四层规律：

| 层次 | 内容 |
|---|---|
| 天地定位 | 乾在上、坤在下（《系辞传》「天地定位」） |
| 先天卦数 | 乾1、兑2、离3、震4、巽5、坎6、艮7、坤8 |
| 方图（空间） | 8×8 方阵：行 = 下卦先天数，列 = 上卦先天数，乾居右下角 |
| 圆图（时间） | 由方图读出：下卦行序 1→8、每行内上卦列序 1→8，乾1→坤64，天道左旋 |

这一套是风水罗盘、后天应用的「公式层」基础。

## 二、应用到了项目的哪里

统一超级大脑此前已经立起**象数结构**（错/综/互卦、卦德、五行、后天方位、消息卦）和**经文本体**（彖传、爻辞、小象），但**缺"先天数 + 时空坐标"**。这篇文章正好补上，成为第三层。

### 新增模块 `fangyuan.py`（时空坐标层）

```
gua64.py   → 经文本体（卦辞/彖/大象/核心义/现代语义）
xiangshu.py → 象数结构（错综互卦/卦德/五行/后天方位/消息卦）
fangyuan.py → 时空坐标（先天数/方图空间位/圆图时间位/先天方位）  ← 本次新增
```

全部由卦的上下卦结构**程序精确推算**，并内置**邵雍标准圆图 64 卦序**作防错锚点，逐位校验，绝不靠记忆硬编。

### 每卦新增 6 个字段（写入 kb_policy.db 的 gua 表）

| 字段 | 含义 | 例：困卦（泽水困） |
|---|---|---|
| `xian_up` / `xian_down` | 上/下卦先天数 | 上2 · 下6 |
| `fang_row` / `fang_col` | 方图坐标（**空间位**） | 行6 · 列2 |
| `yuantu_order` | 圆图时序（**时间位**） | 第 42 位 |
| `xian_fangwei` | 先天方位 | 东南 · 西 |

### 接入圣人思维 SAGE_SYS

「立心→格物→致知→笃行」四步中的【格物】，从原来只看「卦象·五行·义理关系」，升级为同时看「**时空坐标（方图方位 · 圆图时序）**」——回答任何问题时，能落到「何时、何地、何势」，正是「圆图管时间、方图管空间」的义理贯通。
