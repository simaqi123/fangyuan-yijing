## 一、一句话结论

「时空」从**静态坐标**升级成了**可推演的天文历法系统**——现在每一卦都带上了「节气 + 律吕 + 黄道次 + 错/综/互卦推演链」，圣人思维四步能真正答出「何时、何地、何势」。而且你刚学的方圆图，现在在巡检页上能**点着看**了。

## 二、一个关键设计判断（避免埋雷）

先天方圆图（邵雍**先天数**体系）和卦气配节气（汉代**后天**体系）是**两套系统**。如果简单把圆图 64 位线性插值到 24 节气，会自相矛盾——泰卦会同时落在「夏至」和「正月立春」两个位置。

**正确做法：以十二消息卦为桥梁。**
- 辟卦在先天圆图上有固定物理位置，又有权威节气；
- 其余 52 杂卦按「顺时间」方向归入最近的辟卦区间（汉代卦气「辟卦为君、杂卦为臣」之义）。

结果全部对齐、可程序校验：复=十一月冬至、姤=五月夏至、泰=正月立春、乾=四月立夏、坤=十月立冬，无一例外。

## 三、新建的三个层

### 1. `jieqi.py` 历法层
- **24 节气**：太阳黄经每 15° 一节（天文常数），配三候（《时训解》72 候）
- **12 辟卦全息**：卦 → 月 → 地支 → 律吕 → 黄道次 → 节气区间
- **12 律吕**：黄钟(子)…应钟(亥)，源自《礼记·月令》《史记·律书》
- **黄道十二次**：星纪、玄枵…析木，源自《汉书·律历志》分野次度

### 2. `tuilian.py` 卦际推演
给定一卦，输出确定性推演链：
- **此卦** = 现状（卦德/五行/方位/时空坐标/节气）
- **错卦** = 变之极（六爻阴阳全变，物极必反，约半年对转）
- **综卦** = 反之观（卦象上下颠倒，换位重看）
- **互卦** = 中之变（二三四五爻互体，事态中段演变）

实测：困卦（六月小暑）→ 错卦贲（十二月小寒），正好隔半年，阴阳对转。

### 3. `fangyuan_dashboard.py` 可视化
自包含交互 HTML：方图 8×8（空间）+ 圆图 64 位（时间），点任意卦看全息详情。
