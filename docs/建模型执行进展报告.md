## 已完成 ✅

### 阶段 0：GitHub 调研 + 经文交叉校验

**调研结论**（详见《GitHub调研与建模型最终方案.md》）：
- 可借鉴：`bollwarm/ZHOUYI`（数据）、`kentang2017/ichingshifa`（起卦算法）、`jeffcfhung/decoding-iching`（变爻导航）、`qwen-tcm-finetune` + `Qwen3-TCM`（微调模板）
- **差异化空白**：无人把六十四卦做成可训练结构（超立方体 MoE）、无人做圣人思维引擎 —— 我们的核心创新。

**交叉校验**：`zhouyi_verify.py` 用 zhconv 繁转简后逐字比对，结论：
- **我们 `jingwen.py`（64 彖传 + 386 爻辞 + 384 小象）0 处需修正，地基扎实**
- ZHOUYI 反而有 ~15 处录入错字（见龙"再"田 / 初"噬"告 / 以其"夤" / 不"复远"…）

### 阶段 1：时间起卦 + 微调语料

- **`qigua.py`**：梅花易数时间起卦（年月日时→上下卦→动爻→本卦+变卦）+ 时令卦（日期→节气→十二辟卦），复用已有模块、零新依赖。
- **`export_sft.py`**：生成 **504 条 R1 推理格式语料**（64 卦级 + 386 爻级 + 50 义理概念 + 4 圣人思维贯通示例），承载"立心→格物→致知→笃行"四步。已上传 DGX。

### 阶段 2：卦象专家路由层 POC（核心创新）

- **`gua_moe.py`**：六十四卦 = 六维布尔超立方体 64 顶点（±1 对称嵌入）。
  - 错卦 = 对径点（互为相反向量）
  - 动爻 = 沿边相邻顶点（汉明距离 1）
  - 卦际距离 = 汉明距离
- **验证通过**：路由自命中；输入"乾"→ top3 命中「乾 + 小畜 + 履」（两个"变一爻"的相邻卦），结构先验成立。
