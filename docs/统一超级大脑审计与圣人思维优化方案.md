# 统一超级大脑 · 审计报告与圣人思维优化方案

> 审计对象：DGX Spark 上的 OpenClaw 统一超级大脑（8 阶段已建）
> 审计日期：2026-11-10 | 目标：检查逻辑/漏洞/覆盖，并以易经·道家·儒家为根基建立「圣人思维灵魂层」

---

## 一、审计结论（一句话）

现有体系是一套**顶级的「图书馆 + 诚实检索员」**：资料全（1.1 亿字古籍 + 4200 万字超级大脑 + 得到大脑记录）、检索准（FTS + bge-m3 向量 + reranker 三路混合）、纪律严（不编造、标【待核实】）。
但它**还不是「有思想的大脑」**——缺一个把易经、道家、儒家义理立起来的「思想层/灵魂层」，无法做到"问一个油气或中医问题，用圣人思维贯通作答"。

## 三、审计发现的问题

### A 类 · 代码逻辑 bug（具体到行）

1. **`_local_recall` 空 WHERE 会触发 SQL 语法错误**（`dedao_brain.py` L310-319）
   - 当 query 全是标点/符号（如"！！！"）时，`grams` 为空 → `gl=[]` → `where=""` → SQL 变成 `... WHERE  ORDER BY ...`，抛 `OperationalError`。
   - 修复：`if not gl: return []`（先判空再拼 SQL）。

2. **`search_content` 的 snippet 定位不准**（`unified_brain_mcp.py` L93）
   - `idx = text.find(q)` 用原始 query 定位，但 FTS 是分词匹配，原文可能是"桂枝 汤"而 query 是"桂枝汤"，`find` 返回 -1 → snippet 落到前 300 字而非命中处，影响"引据"精准度。
   - 修复：用 FTS 返回的命中词或做二次切词定位。

3. **`hybrid_search` 去重粒度偏粗**（`unified_brain_mcp.py` L349-353）
   - 按 `text[:80]` 去重，FTS snippet 与向量 text 长度/位置不同，可能漏去重或误去重。

4. **记忆层无向量召回**（`dedao_brain.py` L550 `memory_recall`）
   - 长期记忆只用 `LIKE` 字面模糊匹配，语义相关但字面不同的记忆召不回。人脑记忆是语义关联的，这是"人脑式思考"的直接短板。

### B 类 · 安全 / 运维漏洞

5. **8787 巡检页无鉴权且绑 0.0.0.0**（`brain_http_api.py` L110）——**最高优先级**
   - 任何能访问 `<DGX_HOST>:8787` 的设备都能调全部检索/问答/记忆接口，还能通过 `/api/dedao-upload` 上传文件。记忆里已标注"需设 token"但未修。

6. **每次查询重建 chroma client + 重载 HNSW 索引**（`unified_brain_mcp.py` L250-256、`dedao_brain.py` L247-249）
   - 8787 常驻进程每次检索都新建 `PersistentClient`、重载 18.6 万块索引，性能差。这是"看到 cron 新写入"的权宜之计，代价是每次查询都慢。

### C 类 · 覆盖缺口（核心，对应你要的"灵魂"）

7. **没有「义理层」**：1.1 亿字古籍被平铺切成 18 万块，易经的卦爻辞、道德经的章句、四书的篇章**没有结构化**，无法按"义理概念"检索。

8. **图谱粒度太粗**：现有 `tuopu.db` 是"文化图谱"（人物/学派/朝代），只有 76 概念，**没有"义理图谱"**——道·德·仁·义·礼·智·信、阴阳·五行·太极、卦·爻·象·数 之间的哲学关系边缺失。

9. **DED_SYS 是"诚实纪律"，不是"思维框架"**：现有提示词保证"不编造"，但没有圣人思维的认知框架，问答是平铺 RAG，缺"经义视角"贯通。

## 四、核心诊断：缺「义理层」

用一句话概括差距：

```
现状：资料平铺 → 关键词/向量召回 → 老实作答   （图书馆 + 检索员）
目标：义理立心 → 经义检索 + 领域资料 → 贯通作答（有思想的大脑）
```

## 五、圣人思维灵魂层设计（三层）

### 第 1 层 · 经义数据层（把经典立起来）

从 `guji.db` 的 1.1 亿字里，把核心经典**单独结构化**成章句粒度，建一张新库 `jingyi.db`：

| 经 | 内容 | 结构粒度 |
|---|---|---|
| 易（周易 + 十翼） | 64 卦 · 384 爻 · 卦辞/爻辞 · 彖/象/系辞/文言/说卦/序卦/杂卦 | 卦 → 爻 → 辞 |
| 道（道德经、庄子内篇） | 道德经 81 章、逍遥游/齐物论/养生主等 | 章 → 句 |
| 儒（四书五经） | 大学/中庸/论语/孟子；诗/书/礼/易/春秋 | 篇 → 章 → 句 |

每句带义理标签（如"道法自然""中庸""格物致知""与时偕行"）。

### 第 2 层 · 义理图谱层（把思想关系连起来）

扩充 `tuopu.db`，加"义理概念 + 关系边"：

- **易**：太极 → 阴阳 → 四象 → 八卦 → 六十四卦；象、数、理、变、时、位、中、正
- **道**：道、德、自然、无为、不争、柔、静、虚、一、玄
- **儒**：仁、义、礼、智、信、忠、恕、孝、悌、中庸、诚、敬；格物 → 致知 → 诚意 → 正心 → 修身 → 齐家 → 治国 → 平天下

### 第 3 层 · 圣人思维框架层（让 Qwen 会"思考"）

新增一套 `SAGE_SYS` 提示词框架 + 工具，回答任何问题时走四步：

1. **立心**：先对齐圣人价值观（中庸、诚、敬、慎独），不偏激、不武断
2. **格物**：检索「义理层」（经义 + 义理图谱）+「领域资料」（油气/中医/工作）
3. **致知**：用经义贯通领域问题，触类旁通（如用"阴阳平衡"讲油藏压力、用"与时偕行"讲递减规律）
4. **笃行**：落到可执行的具体建议，并诚实标注依据与【待核实】
